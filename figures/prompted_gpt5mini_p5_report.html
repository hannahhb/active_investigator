What worked.     f(k) = k - floor(k/3) - floor((k+7)/10) + floor((k+27)/30)

where:
- floor(k/3) counts numbers ≤ k divisible by 3,
- floor((k+7)/10) counts numbers ≤ k that end with digit 3,
- floor((k+27)/30) restores those counted twice (numbers ≡ 3 (mod 30)).

So the n-th valid number is the smallest k with f(k) = n. For example,
f(554) == 81, therefore the 81st number satisfying the predicate is 554.
